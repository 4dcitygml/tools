Getting started

First, pick one building to edit on the map.

  1. Click a blue square on the map in the top left.
  2. Wait until the buildings finish loading.
  3. Click one of the light-blue buildings shown inside the square.
  4. Attributes appear on the right. Click an editable value to change it.

Changing a value does not send anything by itself. When you change a value, a source selector opens right below it. Only after you choose a source and press "Send changes" is your proposal delivered to the maintainer.

Send changes to the maintainer

The source data is not modified directly; a readable summary for the maintainer is generated from the selected sources and the before/after values.
