# セットアップガイド（初心者向け）

プログラミング環境がなくても、属性エディタで建物属性の修正を提案できます。
初期設定（この 1〜4）は最初の 1 回だけです。所要 30 分ほど（うち大半はデータのダウンロード待ち）。

必要なもの: インターネット接続・GitHub アカウント（無料）・空きディスク 10 GB 程度。

---

## 1. GitHub のアカウントを作る

1. <https://github.com/signup> を開く
2. メールアドレス・パスワード・ユーザー名（半角英数）を入力して登録
3. 届いた確認メールのコードを入力して完了

## 2. 建物データの「フォーク」（自分のコピー）を作る

1. ログインした状態で <https://github.com/4dcitygml/sample-tokyo-station/fork> を開く
2. 緑の **Create fork** ボタンを押す
3. できあがったページの URL（`https://github.com/あなたのID/sample-tokyo-station`）を後で使うのでメモ

## 3. 道具を入れる（データの取得・提案の送信に使います）

### macOS の場合

1. 「ターミナル」アプリ（Launchpad →「その他」）を開き、`git --version` と入力して Enter
   → 「コマンドライン・デベロッパツール」のインストール画面が出たら「インストール」
   （**git と一緒に、エディタの実行に必要な python3 も入ります**）
2. 認証マネージャ **Git Credential Manager** を入れる:
   <https://github.com/git-ecosystem/git-credential-manager/releases> から
   `gcm-osx-*.pkg` をダウンロードしてインストール

### Windows の場合

**この手順は不要です。** 手順 4 の「全部入り zip」に必要な道具（git・認証マネージャ）が
すべて同梱されています。何もインストールしません。

> 認証マネージャが入っていると、最初の送信時に**ブラウザで GitHub にログインするだけ**で
> 認証が済みます（パスワードやトークンの手入力は不要）。

## 4. 属性エディタを起動する

### macOS の場合（zip を展開してターミナル 1 行・警告は出ません）

1. [Releases ページ](https://github.com/4dcitygml/tools/releases) から
   **`citygml-attr-editor-macos.zip`** をダウンロードし、ダブルクリックで展開
2. ターミナルに半角で `python3 `（最後にスペース）と入力し —— **ここではまだ Enter を押さず** ——
   展開されたフォルダの **app.py をターミナルの画面へドラッグ＆ドロップ**。
   `python3 /Users/…/app.py` と 1 行に並んだのを確認してから Enter
   （`>>>` と表示されたら Enter を先に押しています。`exit()` + Enter で抜けてやり直し。
   詳しくはフォルダ内の「READ-ME-FIRST.txt」にも書いてあります）
3. ブラウザに**初回セットアップ画面**が表示されるので、手順 2 でメモした**フォークの URL** を
   貼り付けて **［クローン実行］** → データ（数 GB）の取得が始まります。
   完了すると自動でエディタ画面に切り替わります
4. このとき**デスクトップに「Attribute Editor.command」が自動で作られます**。
   **次回からはこれをダブルクリックするだけ**です（ターミナルはもう使いません。
   お使いの Mac で作られたファイルなので、セキュリティ警告も出ません）

> ターミナルに慣れている方は zip を使わず 1 行でも起動できます:
> `curl -sL https://raw.githubusercontent.com/4dcitygml/tools/main/tools/attr_editor/app.py -o ~/attr_editor.py && python3 ~/attr_editor.py`

### Windows の場合（zip を展開してダブルクリック・インストール不要）

1. [Releases ページ](https://github.com/4dcitygml/tools/releases) から
   **`citygml-attr-editor-windows-full.zip`**（全部入り・git 同梱・約100MB）をダウンロード
2. zip を右クリック → **すべて展開**。展開先は**デスクトップなど浅い場所**にしてください
   （深いフォルダだとパスの長さ制限に触れることがあります）
3. 展開されたフォルダ内の **`start-windows.bat`** をダブルクリック（同梱 Python で起動する
   ためインストール不要です）。
   初回に警告画面が出た場合は **詳細情報 → 実行**（または **実行**）で開けます
   （配布物に署名を付けていないための表示で、異常ではありません）
4. ブラウザに**初回セットアップ画面**が出るので、フォークの URL を貼り付けて **［クローン実行］**

> PATH上のgitに `user.name` と `user.email` をグローバル設定済みなら、全部入りzipでも
> 既存gitとその認証設定を優先します。gitを自分でインストール済みの方は、単体の
> git と Python 3.9 以上を自分でインストール済みの環境でも `start-windows.bat` はそのまま動きます
> （その場合、同梱分は使われません）。

## 5. ふだんの使い方

1. アプリを起動（Mac: デスクトップの「Attribute Editor.command」/ Windows: start-windows.bat をダブルクリック）
2. 地図のメッシュ枠 → 建物をクリック → 右側の属性の値をクリックして修正
3. **［変更内容を送る］** → 修正の理由・根拠を記入 → **［この内容を送る］**
4. ハブでGitHub接続を済ませていれば、管理者が確認する変更案まで自動で作成されます
5. 「送信が完了しました。管理者の確認待ちです」と出たら完了です

> ハブを経由しない単体利用などで「GitHubを開いて送信を完了する」と出た場合だけ、リンク先で
> 緑色の **Create pull request** を押し、確認画面でもう一度同じボタンを押してください。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 起動しても画面が出ない | 黒い画面（ログ）のエラーメッセージを確認。ブラウザで <http://localhost:8765/> を直接開く |
| 「git が見つかりません」 | 手順 3 をやり直し、アプリを再起動 |
| クローンが途中で止まる | 回線の安定した環境で再実行（保存先フォルダを一度削除してから） |
| 送信時に認証エラー | 認証マネージャ（手順 3）が入っているか確認 |
| データを最新にしたい | いったんアプリを終了し、クローンのフォルダで `git pull` を実行（または GitHub のフォークページで Sync fork → 再クローン） |
| （Mac）ランチャーを消してしまった | ターミナルで `python3 ~/Documents/sample-tokyo-station/tools/attr_editor/app.py` を実行すると再作成されます |
